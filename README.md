## Fichiers importants

À la racine tu as surtout `install_all.sql` : tu l’ouvres dans SQL Developer et tu lances tout le script (F5). Il enchaîne les sept fichiers `01_…` à `07_…` (schéma, données, vues, package, audit, transactions, perf).

Le détail de l’appli Java est dans `interface/README.md`.


## Lancer l’interface

Lance `compile.bat` et `run.bat` (ou les `.sh`)
